1. แนวคิด OOP (Object-Oriented Programming)

นิยาม: การมองโปรแกรมเป็นกลุ่มของ "วัตถุ (Object)" ที่มีปฏิสัมพันธ์กัน โดยเน้นการออกแบบจากล่างขึ้นบน (Bottom-Up Design) แตกต่างจาก Procedural Programming ที่เน้นการมองแบบบนลงล่าง (Top-Down / Functions)

องค์ประกอบของ Object:

  • Data (Fields / Attributes): คุณลักษณะหรือข้อมูลที่วัตถุจัดเก็บ
  • Operations (Methods): พฤติกรรมหรือฟังก์ชันในการจัดการข้อมูล

โครงสร้าง Class Diagram:

  • Class Name: ชื่อของคลาส
  • Fields: ข้อมูลในวัตถุ
  • Methods: พฤติกรรม แบ่งหลักๆ เป็น:
    • Setter (Mutator): เมธอดสำหรับบันทึก/แก้ไขข้อมูล
    • Getter (Accessor): เมธอดสำหรับอ่าน/ส่งออกค่าข้อมูล

ความสัมพันธ์ระหว่างคลาส (Class Relationships):

  • is-a (Inheritance): เช่น Student is a Person
  • has-a (Aggregation/Composition): เช่น Car has an Engine
  • uses-a (Dependency): เช่น Student uses a Pen ในเมธอด

Message Passing: การส่งข้อความสั่งการให้วัตถุเริ่มทำงาน หรือปฏิสัมพันธ์ระหว่างวัตถุผ่านการเรียกใช้เมธอด

2. การสร้างชุดข้อมูลทดสอบด้วยการสุ่ม (Random Data Generation)

การสร้างข้อมูลสุ่มผ่าน Class java.util.Random ช่วยสร้างชุดข้อมูลขนาดใหญ่เพื่อทดสอบประสิทธิภาพอัลกอริทึมได้โดยไม่ต้องคีย์ข้อมูลเอง:

  • การสุ่มตัวเลข (Number RNG):
    • nextInt(n): สุ่มจำนวนเต็มตั้งแต่ \(0\) ถึง \(n-1\)
    • nextDouble(): สุ่มเลขทศนิยมตั้งแต่ \(0.0\) ถึง \(1.0\)
  • การสุ่มข้อความ (String RNG): แปลงเลขสุ่มรหัส ASCII เป็นตัวอักษรโดยใช้ Casting (char) โดยอักษรภาษาอังกฤษพิมพ์เล็ก a-z มีรหัส ASCII ในช่วง \(97\) ถึง \(122\)
import java.util.Random;

public class DataGenerator {
    // เมธอดสุ่มข้อความตัวพิมพ์เล็กความยาว n ตัวอักษร
    public static String genRandomString(int n) {
        Random random = new Random();
        String result = "";
        for (int i = 0; i < n; i++) {
            int asciiCode = 97 + random.nextInt(26); // สุ่ม 97-122
            result += (char) asciiCode;
        }
        return result;
    }

    public static void main(String[] args) {
        Random rnd = new Random();
        int randomInt = rnd.nextInt(10); // สุ่ม 0-9
        double randomDouble = 10.0 + rnd.nextDouble(); // สุ่ม 10.0 - 11.0
        String randomStr = genRandomString(8); // สุ่ม String 8 ตัวอักษร
    }
}

ส่วนที่ 2: โครงสร้างข้อมูล Doubly Linked List

Doubly Linked List คือโครงสร้างข้อมูลแบบเชิงเส้นที่ Node แต่ละตัวเก็บตัวชี้ (Pointer/Reference) 2 ทิศทาง ได้แก่ next (ชี้ไป Node ถัดไป) และ prev (ชี้ย้อนกลับไปยัง Node ก่อนหน้า)

1. โครงสร้าง Node และ Class LinkedList

  • Node: ประกอบด้วย data, next, และ prev
  • LinkedList: เก็บตัวชี้ตำแหน่งต้นรายการ (head), ปลายรายการ (tail), และจำนวนสมาชิก (count)
class Node {
    int data;
    Node next;
    Node prev;

    Node(int data) {
        this.data = data;
        this.next = null;
        this.prev = null;
    }
}

class DoublyLinkedList {
    Node head;
    Node tail;
    int count;

    public DoublyLinkedList() {
        this.head = null;
        this.tail = null;
        this.count = 0;
    }
}

2. การดำเนินงานหลัก (Operations)

  • addFirst(int x): นำ Node ใหม่ไปแทรกไว้หน้าสุด
    • ถ้า List ว่าง (head == null): กำหนดให้ทั้ง head และ tail ชี้ไปที่ Node ใหม่
    • ถ้า List ไม่ว่าง: ให้ head.prev = n, n.next = head, แล้วย้าย head = n
  • addLast(int x): นำ Node ใหม่ไปต่อท้ายสุด
    • ถ้า List ไม่ว่าง: ให้ tail.next = n, n.prev = tail, แล้วย้าย tail = n
  • find(int x): ท่องเข้าไปใน List จาก head เพื่อค้นหา Node ที่มีค่าเท่ากับ x แล้วคืนค่า Pointer ของ Node นั้น
public void addFirst(int x) {
    Node n = new Node(x);
    if (head == null) {
        head = n;
        tail = n;
    } else {
        head.prev = n;
        n.next = head;
        head = n;
    }
    count++;
}

public void addLast(int x) {
    Node n = new Node(x);
    if (head == null) {
        head = n;
        tail = n;
    } else {
        tail.next = n;
        n.prev = tail;
        tail = n;
    }
    count++;
}

public Node find(int x) {
    Node current = head;
    while (current != null) {
        if (current.data == x) {
            return current; // พบข้อมูล
        }
        current = current.next;
    }
    return null; // ไม่พบข้อมูล
}

ส่วนที่ 3: โครงสร้างข้อมูล Stack (กองซ้อน)

Stack คือโครงสร้างข้อมูลเชิงเส้นที่ทำงานแบบ LIFO (Last-In, First-Out) ข้อมูลที่ใส่เข้าไปทีหลังสุดจะถูกนำออกมาใช้งานเป็นอันดับแรก

1. การดำเนินงานหลัก (Operations)

  • push(x): นำข้อมูลเข้าสู่ยอด Stack (Top)
  • pop(): นำข้อมูลออกจากยอด Stack และคืนค่านั้น
  • top() / peek(): ดูค่าข้อมูลที่อยู่บนยอด Stack โดยไม่ลบออก
  • isEmpty(): ตรวจสอบว่า Stack ว่างหรือไม่
  • isFull(): ตรวจสอบว่า Stack เต็มหรือไม่ (กรณีสร้างด้วย Array)

2. โครงสร้างภายใน (Implementation)

Stack สามารถสร้างได้ทั้งแบบ Array-based (จำกัดขนาด) และ Linked List-based (ขยายขนาดได้ยืดหยุ่น)

3. การใช้งาน java.util.Stack ใน Java

import java.util.Stack;

public class StackDemo {
    public static void main(String[] args) {
        // แนะนำให้กำหนด Type Parameter เพื่อป้องกัน ClassCastException
        Stack<Integer> stack = new Stack<>();
        stack.push(10);
        stack.push(20);
        stack.push(30);

        System.out.println(stack.peek()); // แสดง 30
        System.out.println(stack.pop());  // ดึง 30 ออก
        System.out.println(stack.empty());// false
    }
}

4. การประยุกต์ใช้งาน Stack (Applications)

4.1 การกลับข้อความ (String Reversing) & การตรวจ Palindrome

นำอักขระแต่ละตัวใส่ Stack แล้ว pop() ออกมาต่อกันเพื่อกลับคำ:

import java.util.Stack;

public class StringApplications {
    public static String reverse(String text) {
        Stack<Character> stack = new Stack<>();
        for (int i = 0; i < text.length(); i++) {
            stack.push(text.charAt(i));
        }
        String reversed = "";
        while (!stack.isEmpty()) {
            reversed += stack.pop();
        }
        return reversed;
    }

    public static boolean isPalindrome(String text) {
        String cleanText = text.replaceAll("\\s+", "").toLowerCase();
        return cleanText.equals(reverse(cleanText));
    }
}

4.2 การแปลง Infix เป็น Postfix (Infix to Postfix Conversion)

กฎเกณฑ์:

  1. อ่าน Expression จากซ้ายไปขวา
  2. ถ้าเป็น Operand (ตัวเลข/ตัวแปร): พิมพ์ออก Output ทันที
  3. ถ้าเป็น '(': push ลง Stack
  4. ถ้าเป็น ')': pop เครื่องหมายใน Stack ออก Output จนกว่าจะเจอ '(' (แล้ว pop '(' ทิ้ง)
  5. ถ้าเป็น Operator:
    • ถ้าความสำคัญ (Precedence) สูงกว่าตัวบนสุดของ Stack หรือ Stack ว่าง ให้ push ลง Stack
    • ถ้าความสำคัญน้อยกว่าหรือเท่ากับ ให้ pop Operator บน Stack ออก Output เรื่อยๆ จนกว่าจะเจอตัวที่ลำดับต่ำกว่า แล้วจึง push Operator ใหม่ลงไป
  6. เมื่อสแกนจบ นำ Operator ที่เหลือใน Stack ออกมาไว้ที่ Output

4.3 การคำนวณผลลัพธ์ Postfix Expression

กฎเกณฑ์: สแกน Expression จากซ้ายไปขวา:

  • ถ้าเจอ Operand: push ลง Stack
  • ถ้าเจอ Operator: pop ค่า 2 ตัวออกจาก Stack (ตัวแรกเป็น Operand2, ตัวที่สองเป็น Operand1) นำมาคำนวณ \( \text{Operand1} \ [\text{Operator}] \ \text{Operand2} \) แล้ว push ผลลัพธ์กลับลง Stack
ตัวอย่างคำนวณ Postfix: 2 3 4 * + 5 -
1. Push 2, 3, 4 ลง Stack → Stack: [2, 3, 4]
2. เจอ *: Pop 4 และ 3 → คำนวณ \(3 \times 4 = 12\) → Push 12 → Stack: [2, 12]
3. เจอ +: Pop 12 และ 2 → คำนวณ \(2 + 12 = 14\) → Push 14 → Stack: [14]
4. Push 5 → Stack: [14, 5]
5. เจอ -: Pop 5 และ 14 → คำนวณ \(14 - 5 = 9\) → Push 9 → Stack: [9]
6. ผลลัพธ์สุดท้าย = 9

ส่วนที่ 4: โครงสร้างข้อมูล Queue และ Deque (คิว และ คิวสองหน้า)

Queue คือโครงสร้างข้อมูลเชิงเส้นที่ทำงานแบบ FIFO (First-In, First-Out) ข้อมูลที่เข้ามาก่อนจะถูกนำออกไปประมวลผลก่อน

1. Queue Operations & Standard Java Methods

การประมวลผล Queue มีตัวชี้ 2 ตำแหน่งคือ front (หัวคิว) และ rear (ท้ายคิว):

การทำงาน แบบสุ่มโยน Exception (Throws Exception) แบบคืนค่าพิเศษ (Returns Special Value)
Insert (เพิ่มข้อมูล) add(e) offer(e)
Remove (นำข้อมูลออก) remove() poll()
Examine (ดูหัวคิว) element() peek()
ข้อควรระวัง: หากเรียก remove() หรือ element() บน Queue ที่ว่างเปล่า จะเกิด NoSuchElementException แต่หากใช้ poll() หรือ peek() จะคืนค่า null

2. การ Implement Queue คลาสต่างๆ ใน Java

  • LinkedList: Queue แบบไร้ขอบเขต (Unbounded Queue)
  • LinkedBlockingQueue<E>(capacity): คิวที่จำกัดขนาดได้ (Bounded Queue) ป้องกันความจำเต็ม
  • ArrayBlockingQueue<E>(capacity): คิวจำกัดขนาดที่สร้างด้วย Array
    • เมธอดเสริม: remainingCapacity() เพื่อดูจำนวนช่องว่างที่เหลือ
import java.util.Queue;
import java.util.LinkedList;
import java.util.concurrent.ArrayBlockingQueue;

public class QueueDemo {
    public static void main(String[] args) {
        // Standard LinkedList Queue
        Queue<String> q = new LinkedList<>();
        q.add("A");
        q.offer("B");
        System.out.println(q.peek()); // A
        q.poll(); // ลบ A

        // Bounded Queue (จำกัดขนาด 2)
        Queue<String> bq = new ArrayBlockingQueue<>(2);
        bq.add("X");
        bq.add("Y");
        // bq.add("Z"); // โยน Exception Queue full!
    }
}

3. Deque (Double Ended Queue)

คิวสองหน้า คือ Queue ที่สามารถเพิ่มและลบข้อมูลได้ทั้งทาง Front (หัวคิว) และ Rear (ท้ายคิว)

การทำงาน ด้านหน้า (Head / First) ด้านหลัง (Tail / Last)
Insert addFirst(e) / offerFirst(e) addLast(e) / offerLast(e)
Remove removeFirst() / pollFirst() removeLast() / pollLast()
Examine getFirst() / peekFirst() getLast() / peekLast()

คลาสที่ใช้งาน Deque: ArrayDeque, LinkedList, LinkedBlockingDeque

4. ตัวอย่างโจทย์ประยุกต์: การสลับทางร่วมของรถยนต์ (Traffic Intersection)

จำลองการสลับรถจากถนน 2 สาย (A และ B) เข้าสู่ถนนร่วม C:

import java.util.*;

public class TrafficSimulation {
    public static void main(String[] args) {
        Queue<String> QA = new LinkedList<>(Arrays.asList("A1", "A2", "A3", "A4"));
        Queue<String> QB = new LinkedList<>(Arrays.asList("B1", "B2", "B3", "B4"));
        Queue<String> QC = new LinkedList<>();

        // สลับรถเข้าถนน C ทีละคันสลับกัน
        while (QA.peek() != null || QB.peek() != null) {
            if (QA.peek() != null) QC.add(QA.remove());
            if (QB.peek() != null) QC.add(QB.remove());
        }

        System.out.println("QC: " + QC); 
        // ผลลัพธ์: [A1, B1, A2, B2, A3, B3, A4, B4]
    }
}

ส่วนที่ 5: โครงสร้างข้อมูล Priority Queue (คิวลำดับความสำคัญ)

Priority Queue คือคิวพิเศษที่ข้อมูลภายในจะถูกจัดเรียงตาม ลำดับความสำคัญ (Priority) ข้อมูลที่มีความสำคัญสูงที่สุดจะถูกจัดให้อยู่หน้าสุดของคิวเสมอ และจะถูกนำออกไปประมวลผลเป็นอันดับแรก

1. คุณลักษณะสำคัญ

  • ใช้โครงสร้างข้อมูลแบบ Heap Tree (Binary Heap) ในการบริหารจัดการข้อมูลภายใน
  • การแสดงผลผ่าน System.out.println() จะแสดงในรูปแบบการท่องต้นไม้แบบ Breadth-First Search (BFS)
  • ไม่อนุญาต ให้ใส่ค่า null หรือวัตถุที่ไม่สามารถเปรียบเทียบค่าได้ (Non-comparable Objects)

2. ประเภทการจัดเรียง (Heap Types)

  • Min Heap (Natural Ordering): ค่าที่น้อยที่สุดจะมีความสำคัญสูงสุด (เรียงจากน้อยไปมาก) เป็นค่า Default ของ Java
  • Max Heap: ค่าที่มากที่สุดจะมีความสำคัญสูงสุด (เรียงจากมากไปน้อย) สามารถใช้ Collections.reverseOrder()
import java.util.Queue;
import java.util.PriorityQueue;
import java.util.Collections;

public class PriorityQueueDemo {
    public static void main(String[] args) {
        // Min Heap (Natural Ordering)
        Queue<Integer> minPq = new PriorityQueue<>();
        minPq.add(3);
        minPq.add(1);
        minPq.add(2);
        System.out.println(minPq.poll()); // คืนค่า 1 (ค่าน้อยสุดออกก่อน)

        // Max Heap (Reverse Ordering)
        Queue<Integer> maxPq = new PriorityQueue<>(Collections.reverseOrder());
        maxPq.add(1);
        maxPq.add(3);
        maxPq.add(2);
        System.out.println(maxPq.poll()); // คืนค่า 3 (ค่ามากสุดออกก่อน)
    }
}

3. การใช้งาน Custom Objects และ Comparator

หากต้องการนำ Class ที่สร้างขึ้นเอง (เช่น Student) ใส่ลงใน Priority Queue ต้องเขียน Comparator เพื่อบอกกฎการเปรียบเทียบ มิฉะนั้นจะเกิด ClassCastException

import java.util.*;

class Student {
    String code;
    String name;
    double gpa;

    public Student(String code, String name, double gpa) {
        this.code = code;
        this.name = name;
        this.gpa = gpa;
    }

    @Override
    public String toString() {
        return name + " (" + gpa + ")";
    }
}

// สร้าง Comparator สำหรับเรียงลำดับเกรดเฉลี่ย (GPA)
class StudentGPAComparator implements Comparator<Student> {
    @Override
    public int compare(Student s1, Student s2) {
        // เรียงจาก GPA มากไปน้อย (Descending)
        if (s1.gpa < s2.gpa) return 1;
        else if (s1.gpa > s2.gpa) return -1;
        return 0;
    }
}

public class CustomPriorityQueue {
    public static void main(String[] args) {
        // ส่ง Comparator เข้าไปใน Constructor
        Queue<Student> pq = new PriorityQueue<>(new StudentGPAComparator());
        pq.add(new Student("001", "Bob", 3.04));
        pq.add(new Student("002", "Alice", 2.58));
        pq.add(new Student("003", "Charlie", 3.55));

        // ดึงนักเรียนที่มี GPA สูงสุดออกมา
        while (!pq.isEmpty()) {
            System.out.println(pq.poll());
        }
        // Output:
        // Charlie (3.55)
        // Bob (3.04)
        // Alice (2.58)
    }
}
