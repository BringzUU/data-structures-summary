📌 ภาพรวมโปรแกรม

นี่คือโปรแกรม GUI (Swing) จำลองระบบ "รับเลี้ยงสัตว์" ประกอบด้วยโครงสร้างข้อมูล 3 แบบที่เขียนขึ้นเอง (ไม่ใช้ของ java.util):

LinkedList เก็บ Pet ที่รอรับเลี้ยง (doubly linked list)
Stack เก็บ Adopter ที่รอคิว (LIFO)
Queue เก็บ Adopter ที่ "รับเลี้ยงสำเร็จ" แล้ว (FIFO)

ผู้ใช้กดปุ่มบน GUI เพื่อ: สุ่มข้อมูล → เพิ่มเข้าโครงสร้าง → จับคู่ Pet กับ Adopter → เรียงลำดับ → บันทึก/โหลดไฟล์

PNode Node ของ LinkedList (Pet)

โหนดของ doubly-linked list สำหรับเก็บ Pet หนึ่งตัว

PNode
 ├─ data : Pet     (ข้อมูลจริง)
 ├─ next : PNode   (โหนดถัดไป)
 └─ prev : PNode   (โหนดก่อนหน้า)

Constructor รับ Pet เข้ามาแล้วเซ็ต next, prev เป็น null ก่อนเสมอ

ANode Node ของ Stack & Queue (Adopter)

โครงสร้างเหมือน PNode ทุกอย่าง เพียงแต่เก็บ Adopter แทน Pet

ใช้ร่วมกันทั้งในคลาส Stack และ Queue ด้านล่าง

LinkedList เก็บ Pet ที่รอรับเลี้ยง

Doubly-linked list มี head, tail, size

add(Pet a)

สร้าง PNode ใหม่ แล้วต่อเข้าไปทาง ท้าย (tail) ของลิสต์ — ถ้าลิสต์ว่างให้ head = tail = node เลย

remove()

ลบสัตว์ตัวที่อยู่ ท้ายลิสต์ (tail) แล้วคืนค่ากลับไป — ถ้าลิสต์ว่างคืน null

✅ แก้แล้ว: ตอนนี้เช็คว่าถ้าลบจนไม่เหลือ node จะเซ็ต head = null ด้วย และถ้ายังเหลือจะตัด tail.next = null เพื่อไม่ให้มี dangling reference (เมื่อก่อนพลาดจุดนี้ ทำให้ add() ครั้งถัดไปพัง)

isEmpty(), size(), getHead(), toArray()

เมธอดช่วยมาตรฐาน — toArray() วนจาก head ไป next เรื่อยๆ แปลงเป็น Pet[] เพื่อเอาไปแสดงในตาราง

⚠️ ข้อสังเกต: add() เพิ่มที่ tail และ remove() ก็ลบที่ tail เหมือนกัน → พฤติกรรมจริงคือ Stack (LIFO) ไม่ใช่คิวปกติ ถ้าต้องการให้ "ตัวที่เพิ่มก่อนถูกจับคู่ก่อน" ต้องเปลี่ยนไปลบจาก head แทน

Stack เก็บ Adopter ที่รอคิว — LIFO

ใช้ singly-linked node (ANode) โดยมีแค่ top ตัวเดียว

  • push(Adopter A) — สร้างโหนดใหม่ วางไว้บนสุด (node.next = top; top = node;)
  • pop() — เอาตัวบนสุดออก (top = top.next) แล้วคืนค่า
  • isEmpty(), size(), getTop(), toArray() — เมธอดช่วยมาตรฐาน

ล่าสุดที่ push เข้ามาจะเป็นตัวแรกที่ถูก pop ออก (คนที่กด "AddAdopter" ทีหลังจะได้จับคู่กับสัตว์ก่อน)

Queue เก็บ Adopter ที่รับเลี้ยงสำเร็จแล้ว — FIFO

Doubly-linked list ของ ANode มี front และ last

  • offer(Adopter a) — เพิ่มเข้าทาง last
  • poll() — เอาออกทาง front (คนแรกที่เข้ามาก่อน) พร้อมเช็คกรณีเหลือ node เดียวให้เคลียร์ last ด้วย — เมธอดนี้เขียนถูกต้องแล้ว (ไม่มีบั๊กแบบที่เจอใน LinkedList.remove())
  • toArray() — แปลงเป็น Adopter[]
  • clear() — เคลียร์ทั้ง front, last, size

sortByid()

เรียงลำดับสมาชิกใน queue ตาม id จากน้อยไปมาก โดยใช้ Bubble Sort:

1. toArray()        → ดึงข้อมูลทั้งหมดออกมาเป็น array ก่อน
2. bubble sort       → เรียงตาม id (วน 2 loop เทียบทีละคู่ สลับถ้าลำดับผิด)
3. clear()           → ล้าง queue เดิมทิ้งให้หมด
4. offer() วนใหม่    → เติมสมาชิกที่เรียงแล้วกลับเข้า queue ตามลำดับ

เป็นวิธี "แปลงเป็น array → sort → ใส่กลับ" ซึ่งใช้ได้ผล แม้จะไม่ efficient เท่าการ sort linked list ตรงๆ (แต่ข้อมูลจำนวนน้อยจึงไม่มีปัญหา)

💾 ระบบ Save / Load

ใช้ Java Object Serialization มาตรฐาน:

Save:  Queue → ObjectOutputStream → data.ser
Load:  data.ser → ObjectInputStream → Queue (cast กลับ)

เนื่องจาก Queue เก็บ ANode ซึ่งเก็บ Adopter ซึ่งเก็บ Pet — ทุกคลาสในสายนี้ต้อง Serializable หมด ไม่งั้นจะ error ทันทีตอน writeObject()

💡 หมายเหตุ: data.ser จะถูกสร้าง/อ่านที่ working directory ของโปรแกรม (มักจะเป็นโฟลเดอร์ project ตอนรันจาก IDE) — ถ้า Load แล้วหาไฟล์ไม่เจอจะโชว์ dialog "Load error: ..."

🛠️ สรุปจุดที่แก้ไปแล้ว / ที่ยังควรพิจารณา

✅ แก้แล้วในเวอร์ชันนี้

  • เพิ่ม implements Serializable ให้ Pet, Adopter, PNode, ANode, LinkedList, Stack, Queue — ทำให้ Save/Load ทำงานได้จริง
  • LinkedList.remove() เซ็ต head = null เมื่อลบ node สุดท้าย และตัด tail.next = null กัน dangling reference

⚠️ ยังควรพิจารณาเพิ่ม (ไม่ใช่บั๊กที่ทำให้พัง แต่เป็นจุดออกแบบ)

  • LinkedList ทำงานแบบ LIFO ไม่ใช่ FIFO — ถ้าต้องการให้ Pet ที่เพิ่มก่อนถูกจับคู่ก่อน ต้องแก้ remove() ให้ลบจาก head แทน tail
  • id สุ่มไม่กันชนกัน — สองตัวอาจได้ id ซ้ำกันได้ ถ้าต้องใช้ id เป็นตัวอ้างอิงเฉพาะควรเช็คซ้ำก่อนสุ่มเสร็จ
  • ชื่อคลาส LinkedList, Stack, Queue ซ้ำกับ java.util — ตอนนี้ไม่พังเพราะไม่ได้ import java.util.* แต่เสี่ยงเกิด ambiguity ถ้ามีการ import เพิ่มในอนาคต แนะนำเปลี่ยนชื่อ เช่น PetList, AdopterStack, AdopterQueue
  • RemovePet / RemoveAdopter ไม่แจ้งเตือนผู้ใช้เมื่อว่าง — ปุ่มอื่นๆ (เช่น Addpet) มีการเช็ค null แล้วโชว์ข้อความ แต่สองปุ่มนี้ไม่มี ถึงจะไม่ error (เพราะ remove()/pop() เช็ค isEmpty() ให้แล้ว) แต่ผู้ใช้จะไม่รู้ว่ากดไปแล้วไม่มีอะไรเกิดขึ้น

class Pet implements Serializable { // ประกาศคลาส Pet สำหรับเก็บข้อมูลสัตว์เลี้ยง (รองรับ Save/Load)
    int id; // ประกาศตัวแปรเก็บรหัสสัตว์เลี้ยง
    String name; // ประกาศตัวแปรเก็บชื่อสัตว์เลี้ยง
    String type; // ประกาศตัวแปรเก็บประเภทสัตว์เลี้ยง (cat/dog)
    int age; // ประกาศตัวแปรเก็บอายุสัตว์เลี้ยง

    public Pet(int id, String name, String type, int age) { // ตัวสร้างคลาส (Constructor) รับค่าเริ่มต้น 4 ค่า
        this.id = id; // กำหนดค่า id จากพารามิเตอร์ให้ตัวแปร id ของคลาส
        this.name = name; // กำหนดค่า name จากพารามิเตอร์ให้ตัวแปร name ของคลาส
        this.type = type; // กำหนดค่า type จากพารามิเตอร์ให้ตัวแปร type ของคลาส
        this.age = age; // กำหนดค่า age จากพารามิเตอร์ให้ตัวแปร age ของคลาส
    }

    public int getId() { // เมธอดดึงค่า id
        return id; // ส่งคืนค่า id
    }

    public String getName() { // เมธอดดึงค่า name
        return name; // ส่งคืนค่า name
    }

    public String getType() { // เมธอดดึงค่า type
        return type; // ส่งคืนค่า type
    }

    public int getAge() { // เมธอดดึงค่า age
        return age; // ส่งคืนค่า age
    }

    @Override // กำหนดการเขียนทับเมธอดเดิมของ Java
    public String toString() { // เมธอดแปลงข้อมูล Pet เป็นข้อความ
        return id + "," + name + "," + type + "," + age; // ส่งคืนข้อความรวมข้อมูล Pet ขั้นด้วยเครื่องหมายจุลภาค
    }
}

    public void setPet(Pet pet) { // เมธอดผูก Pet เข้ากับ Adopter ตัวนี้

        }
        return id + "," + name + "," + gender + "," + age + "," + salary + "," + Petname; // ส่งคืนข้อความรวมข้อมูล Adopter
    }

class PNode implements Serializable { // ประกาศคลาส PNode สำหรับทำเป็นโหนดของ Pet ใน LinkedList
    Pet data; // ตัวแปรเก็บข้อมูลสัตว์เลี้ยง
    PNode next, prev; // ตัวแปรเก็บตำแหน่งโหนดถัดไป (next) และโหนดก่อนหน้า (prev)

    public PNode(Pet data) { // Constructor รับข้อมูล Pet
        this.data = data; // บันทึกข้อมูล Pet เข้าโหนด
        this.next = null; // กำหนดตัวเชื่อมถัดไปเป็น null
        this.prev = null; // กำหนดตัวเชื่อมก่อนหน้าเป็น null
    }
}

class ANode implements Serializable { // ประกาศคลาส ANode สำหรับทำเป็นโหนดของ Adopter ใน Stack และ Queue
    Adopter data; // ตัวแปรเก็บข้อมูลผู้ขอรับเลี้ยง
    ANode next, prev; // ตัวแปรเก็บตำแหน่งโหนดถัดไป และโหนดก่อนหน้า

    public ANode(Adopter data) { // Constructor รับข้อมูล Adopter
        this.data = data; // บันทึกข้อมูล Adopter เข้าโหนด
        this.next = null; // กำหนดตัวเชื่อมถัดไปเป็น null
        this.prev = null; // กำหนดตัวเชื่อมก่อนหน้าเป็น null
    }
}

class LinkedList implements Serializable { // ประกาศคลาส LinkedList สำหรับเก็บรายการ Pet
    PNode head; // ตัวแปรชี้โหนดแรกสุด
    PNode tail; // ตัวแปรชี้โหนดท้ายสุด
    int size; // ตัวแปรนับจำนวนสมาชิก

    public LinkedList() { // Constructor ของ LinkedList
        this.head = null; // ตั้งค่าโหนดแรกเป็น null
        this.tail = null; // ตั้งค่าโหนดท้ายเป็น null
        this.size = 0; // ตั้งค่าจำนวนสมาชิกเริ่มต้นเป็น 0
    }

    public void add(Pet a) { // เมธอดเพิ่ม Pet เข้าท้ายรายการ
        PNode node = new PNode(a); // สร้างโหนดใหม่จากวัตถุ Pet
        if (head == null) { // ถ้าลิสต์ยังว่างอยู่
            head = tail = node; // ให้ head และ tail ชี้ไปที่โหนดใหม่นี้พร้อมกัน
        } else { // ถ้าลิสต์มีข้อมูลอยู่แล้ว
            tail.next = node; // เอาโหนดใหม่ต่อท้าย tail เดิม
            node.prev = tail; // ให้ prev ของโหนดใหม่ชี้กลับมาที่ tail เดิม
            tail = node; // ขยับตำแหน่ง tail ให้มาเป็นโหนดใหม่
        }
        size++; // เพิ่มจำนวนสมาชิกขึ้น 1
    }

    public Pet remove() { // เมธอดดึง Pet ตัวท้ายสุดออกจากลิสต์
        if (isEmpty()) { // ถ้าลิสต์ว่าง
            return null; // คืนค่า null
        }
        Pet temp = tail.data; // ดึงข้อมูล Pet ของตัวท้ายสุดมาพักไว้
        tail = tail.prev; // ถอย tail ไปยังโหนดก่อนหน้า

        if (tail == null) { // ถ้าถอยแล้วทำให้ลิสต์ว่างเปล่า
            head = null; // ล้างค่า head ให้เป็น null ด้วย
        } else { // ถ้ายังมีสมาชิกเหลืออยู่
            tail.next = null; // ตัดสายเชื่อมไปยังโหนดที่เพิ่งถูกลบออก
        }

        size--; // ลดจำนวนสมาชิกลง 1
        return temp; // ส่งคืนข้อมูล Pet ที่ดึงออกมา
    }

    boolean isEmpty() { // เมธอดเช็คว่าลิสต์ว่างหรือไม่
        return head == null; // คืนค่า true ถ้า head เป็น null
    }

    int size() { // เมธอดดึงขนาดจำนวนสมาชิก
        return size; // คืนค่าขนาดปัจจุบัน
    }

    PNode getHead() { // เมธอดดึงโหนดแรก
        return head; // คืนค่า head
    }

    Pet[] toArray() { // เมธอดแปลง LinkedList เป็น Array ของ Pet
        Pet[] arr = new Pet[size]; // สร้าง Array ตามขนาดจำนวนสมาชิกที่มี
        PNode a = head; // เริ่มต้นที่โหนดแรก
        int i = 0; // ตัวนับ Index ของ Array
        while (a != null) { // วนลูปตราบใดที่ยังมีโหนดถัดไป
            arr[i] = a.data; // เก็บข้อมูล Pet ใส่ใน Array
            a = a.next; // ขยับไปโหนดถัดไป
            i++; // เพิ่มค่า Index
        }
        return arr; // ส่งคืน Array สัตว์เลี้ยงทั้งหมด
    }
}

class Stack implements Serializable { // ประกาศคลาส Stack สำหรับเก็บ Adopter (แบบมาทีหลังออกก่อน LIFO)
    ANode top; // ตัวแปรชี้โหนดบนสุดของ Stack
    int size; // ตัวแปรเก็บจำนวนสมาชิก

    public Stack() { // Constructor ของ Stack
        top = null; // ตั้งค่าโหนดบนสุดเป็น null
        size = 0; // ตั้งค่าจำนวนสมาชิกเริ่มต้นเป็น 0
    }

    void push(Adopter A) { // เมธอดใส่ Adopter เข้า Stack
        ANode node = new ANode(A); // สร้างโหนดใหม่
        node.next = top; // ให้ตัวเชื่อมของโหนดใหม่ชี้ไปยัง top เดิม
        top = node; // ขยับ top ให้มาชี้ที่โหนดใหม่
        size++; // เพิ่มจำนวนสมาชิกขึ้น 1
    }

    Adopter pop() { // เมธอดดึง Adopter ตัวบนสุดออกจาก Stack
        if (isEmpty()) { // ถ้า Stack ว่าง
            return null; // คืนค่า null
        }
        Adopter temp = top.data; // เก็บข้อมูล Adopter ตัวบนสุดไว้
        top = top.next; // เลื่อน top ไปยังโหนดถัดไปด้านล่าง
        size--; // ลดจำนวนสมาชิกลง 1
        return temp; // ส่งคืนข้อมูล Adopter ที่ดึงออก
    }

    boolean isEmpty() { // เมธอดเช็ค Stack ว่าง
        return top == null; // คืนค่า true ถ้า top เป็น null
    }

    int size() { // เมธอดดึงขนาด Stack
        return size; // คืนค่าจำนวนสมาชิก
    }

    ANode getTop() { // เมธอดดึงโหนดบนสุด
        return top; // คืนค่า top
    }

    Adopter[] toArray() { // เมธอดแปลง Stack เป็น Array
        Adopter[] arr = new Adopter[size]; // สร้าง Array ขนาดเท่าสมาชิกใน Stack
        ANode a = top; // เริ่มดึงจาก top Down
        int i = 0; // ตัวนับ Index
        while (a != null) { // วนลูปอ่านจนกว่าจะหมด Stack
            arr[i] = a.data; // บันทึกข้อมูลใส่ Array
            a = a.next; // ขยับลงล่าง
            i++; // เพิ่ม Index
        }
        return arr; // ส่งคืน Array ของ Adopter
    }
}

class Queue implements Serializable { // ประกาศคลาส Queue เก็บ Adopter ที่จับคู่สำเร็จแล้ว (แบบเข้าก่อนออกก่อน FIFO)
    ANode front; // ตัวแปรชี้หัวคิว
    ANode last; // ตัวแปรชี้ท้ายคิว
    int size; // ตัวแปรเก็บจำนวนสมาชิก

    Queue() { // Constructor ของ Queue
        front = null; // ตั้งค่าหัวคิวเป็น null
        last = null; // ตั้งค่าท้ายคิวเป็น null
        size = 0; // ตั้งค่าสมาชิกเป็น 0
    }

    void offer(Adopter a) { // เมธอดต่อคิวท้ายสุด
        ANode node = new ANode(a); // สร้างโหนดใหม่
        if (last == null) { // ถ้าคิวว่างเปล่า
            front = last = node; // ให้ front และ last ชี้ที่โหนดใหม่นี้
        } else { // ถ้ามีสมาชิกในคิวแล้ว
            last.next = node; // ต่อโหนดใหม่เข้าท้ายคิว
            node.prev = last; // ให้ prev ของโหนดใหม่ชี้กลับไปที่ last เดิม
            last = node; // ขยับ last มาชี้โหนดใหม่
        }
        size++; // เพิ่มจำนวนสมาชิก
    }

    Adopter poll() { // เมธอดดึงคิวหน้าสุดออก
        if (isEmpty()) { // ถ้าคิวว่าง
            return null; // คืนค่า null
        }
        Adopter temp = front.data; // เก็บข้อมูลหน้าคิวไว้
        front = front.next; // ขยับ front ไปคนถัดไป
        if (front != null) { // ถ้ายังมีสมาชิกเหลือในคิว
            front.prev = null; // ตัดตัวเชื่อมกลับด้านหน้า
        } else { // ถ้าคิวว่างแล้ว
            last = null; // ล้างค่า last เป็น null
        }
        size--; // ลดจำนวนสมาชิก
        return temp; // คืนค่าข้อมูลที่ถูกดึงออก
    }

    boolean isEmpty() { // เมธอดเช็คคิวว่าง
        return front == null; // คืนค่า true ถ้าหน้าคิวเป็น null
    }

    int size() { // เมธอดดึงขนาดคิว
        return size; // คืนค่าจำนวนสมาชิก
    }

    ANode getFront() { // เมธอดดึงโหนดหน้าคิว
        return front; // คืนค่า front
    }

    Adopter[] toArray() { // เมธอดแปลง Queue เป็น Array
        Adopter[] arr = new Adopter[size]; // สร้าง Array ขนาดเท่าคิว
        ANode a = front; // เริ่มจากหัวคิว
        int i = 0; // ตัวนับ Index
        while (a != null) { // วนลูปจนจบแถวคิว
            arr[i] = a.data; // ใส่ข้อมูลลง Array
            a = a.next; // ขยับไปคนถัดไป
            i++; // เพิ่ม Index
        }
        return arr; // คืนค่า Array สมาชิกในคิว
    }

    void sortByid() { // เมธอดเรียงลำดับสมาชิกใน Queue ตาม id จากน้อยไปมาก
        Adopter[] arr = toArray(); // ดึงข้อมูลคิวทั้งหมดออกมารวมเป็น Array

        for (int j = 0; j < arr.length - 1; j++) { // ลูปนอกสำหรับ Bubble Sort
            for (int i = 0; i < arr.length - 1; i++) { // ลูปในเปรียบเทียบข้อมูลทีละคู่
                if (arr[i].getId() > arr[i + 1].getId()) { // ถ้า id ตัวหน้ามากกว่า id ตัวหลัง
                    Adopter temp = arr[i]; // เอาตัวหน้ามาพักใน temp
                    arr[i] = arr[i + 1]; // สลับเอาตัวหลังมาใส่แทนตัวหน้า
                    arr[i + 1] = temp; // เอา temp มาใส่ตำแหน่งตัวหลัง
                }
            }
        }
        clear(); // ล้าง Queue เดิมออกให้หมด
        for (int i = 0; i < arr.length; i++) { // วนลูปอ่านข้อมูลที่เรียงลำดับเสร็จแล้ว
            offer(arr[i]); // ใส่สมาชิกลับเข้า Queue ทีละตัวตามลำดับใหม่
        }
    }

    void clear() { // เมธอดล้างข้อมูลคิว
        front = null; // ตั้งค่าหน้าคิวเป็น null
        last = null; // ตั้งค่าท้ายคิวเป็น null
        size = 0; // ตั้งค่าจำนวนสมาชิกเป็น 0
    }
}

    @SuppressWarnings("unchecked") // ปิดการเตือนความปลอดภัยประเภทข้อมูลของคอมไพเลอร์

    private void jButton1ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 1: กดเพื่อสุ่ม Pet (GenPet)
        currentPet = genPString(); // สัตว์เลี้ยงปัจจุบัน = สร้างแบบสัตว์เลี้ยงแบบสุ่ม
        jTextField1.setText(currentPet.toString()); // แสดงผลข้อมูลสัตว์เลี้ยงที่เพิ่งสุ่มในช่องข้อความ jTextField1
    }

    private void jButton2ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 2: กดเพื่อเพิ่ม Pet ลงลิสต์ (AddPet)
        if (currentPet == null) { // ถ้ายังไม่ได้กดสุ่ม Pet (ตัวแปรเป็น null)
            jTextField1.setText("Press GenPet"); // แจ้งเตือนในช่องข้อความให้กด GenPet ก่อน
            return; // จบการทำงานฟังก์ชันทันที
        }
        list.add(currentPet); // เพิ่มสัตว์เลี้ยงปัจจุบันเข้า LinkedList
        updateTable1(); // อัปเดตตารางที่ 1 เพื่อโชว์สัตว์เลี้ยงล่าสุด
        currentPet = null; // ล้างค่าสัตว์เลี้ยงปัจจุบันให้เป็น null
        jTextField1.setText(""); // เคลียร์ช่องข้อความให้เป็นช่องว่าง
    }

    private void jButton3ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 3: กดเพื่อลบ Pet ออก (RemovePet)
        list.remove(); // ลบสัตว์เลี้ยงตัวท้ายสุดออกจาก LinkedList
        updateTable1(); // รีเฟรชตารางที่ 1 ใหม่
    }

    private void jButton4ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 4: กดเพื่อสุ่ม Adopter (GenAdopter)
        currentAdopter = genAString(); // ผู้ขอรับเลี้ยงปัจจุบัน = สร้างแบบผู้ขอรับเลี้ยงแบบสุ่ม
        jTextField2.setText(currentAdopter.toString()); // แสดงข้อมูลผู้ขอรับเลี้ยงสุ่มล่าสุดลงใน jTextField2
    }

    private void jButton5ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 5: กดเพื่อเพิ่ม Adopter ลง Stack (AddAdopter)
        if (currentAdopter == null) { // ถ้ายังไม่ได้กดสุ่ม Adopter
            jTextField2.setText("Press GenAdopter"); // แจ้งเตือนในช่องข้อความให้กด GenAdopter ก่อน
            return; // จบการทำงานฟังก์ชันทันที
        }
        stack.push(currentAdopter); // ใส่ผู้ขอรับเลี้ยงปัจจุบันเข้า Stack (วางบนสุด)
        updateTable2(); // รีเฟรชตารางที่ 2
        currentAdopter = null; // ล้างค่าผู้ขอรับเลี้ยงปัจจุบันเป็น null
        jTextField2.setText(""); // เคลียร์ช่องข้อความ
    }

    private void jButton6ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 6: กดเพื่อลบ Adopter ออก (RemoveAdopter)
        stack.pop(); // เอาผู้ขอรับเลี้ยงตัวบนสุดออกจาก Stack
        updateTable2(); // รีเฟรชตารางที่ 2 ใหม่
    }

    private void jButton7ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 7: กดจับคู่สัตว์เลี้ยงกับผู้รับเลี้ยง (AssignPet)
        if (list.isEmpty() || stack.isEmpty()) { // ถ้าลิสต์สัตว์เลี้ยงหรือ Stack ผู้รับเลี้ยงว่างเปล่า
            return; // ยกเลิกการทำงานทันที
        }
        Adopter x = stack.pop(); // ดึงผู้ขอรับเลี้ยงคนบนสุดมาจาก Stack
        Pet y = list.remove(); // ดึงสัตว์เลี้ยงตัวท้ายสุดมาจาก LinkedList
        x.setPet(y); // นำสัตว์เลี้ยง y ผูกจับคู่ให้กับผู้ขอรับเลี้ยง x
        queue.offer(x); // นำคู่สำเร็จแล้วเพิ่มต่อเข้า Queue รับเลี้ยงสำเร็จ
        updateTable1(); // รีเฟรชตารางสัตว์เลี้ยง
        updateTable2(); // รีเฟรชตารางผู้รับเลี้ยง
        updateTable3(); // รีเฟรชตารางคู่รับเลี้ยงสำเร็จ
    }

    private void jButton8ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 8: กดเพื่อเรียงลำดับข้อมูลคิว (Sort)
        queue.sortByid(); // สั่งให้ Queue เรียงลำดับสมาชิกตาม id จากน้อยไปมาก
        updateTable3(); // รีเฟรชตารางคู่รับเลี้ยงสำเร็จเพื่อแสดงลำดับใหม่
    }

    private void jButton9ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 9: กดเพื่อบันทึกข้อมูลลงไฟล์ (Save)
        try { // เริ่มต้นบล็อกจับ Error การจัดการไฟล์
            ObjectOutputStream out = new ObjectOutputStream(new FileOutputStream("data.ser")); // เปิดสตรีมสร้าง/เขียนไฟล์ data.ser
            out.writeObject(queue); // แปลงวัตถุ Queue ทั้งก้อนและเขียนลงไฟล์
            out.close(); // ปิดการเชื่อมต่อสตรีมไฟล์
            JOptionPane.showMessageDialog(this, "Save data.ser Success"); // แสดงหน้าต่าง Pop-up แจ้งบันทึกสำเร็จ
        } catch (Exception e) { // ถ้าระหว่างทำงานเกิดข้อผิดพลาด
            JOptionPane.showMessageDialog(this, "Save error: " + e.getMessage()); // แสดง Pop-up ข้อความ Error
        }
    }

    private void jButton10ActionPerformed(java.awt.event.ActionEvent evt) { // ปุ่ม 10: กดเพื่อดึงข้อมูลจากไฟล์กลับมา (Load)
        try { // เริ่มบล็อกจับ Error
            ObjectInputStream in = new ObjectInputStream(new FileInputStream("data.ser")); // เปิดสตรีมอ่านไฟล์ data.ser
            queue = (Queue) in.readObject(); // อ่าน Object ในไฟล์และแปลงประเภทกลับมาเป็น Queue
            in.close(); // ปิดไฟล์
            updateTable3(); // รีเฟรชตารางที่ 3 แสดงผลข้อมูลที่โหลดมาได้
            JOptionPane.showMessageDialog(this, "Load data.ser Suc"); // แสดง Pop-up โหลดสำเร็จ
        } catch (Exception e) { // ถ้าอ่านไฟล์ไม่ได้ หรือไม่เจอไฟล์
            JOptionPane.showMessageDialog(this, "Load error: " + e.getMessage()); // แสดง Pop-up ข้อความ Error
        }
    }
